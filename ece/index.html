Research Focus

I have encountered systems challenges while building AI applications. These experiences motivate my interest in workload characterization, inference scheduling, and hardware-aware performance modeling.

Accelerating LLM-based knowledge graph construction

ETRI · LLM batch execution · GPU memory management

Sequential OpenIE inference took approximately three days per technical manual and encountered GPU memory failures. I grouped prompts of similar lengths into batches and halved batches that exceeded GPU memory before retrying.

Processing time fell from approximately 3 days to 1.5 days with the same model and manual, enabling experiments on three additional manuals.

Serving multiple models on a single GPU

4CO4CO · Multimodal AI · Resource constraints

For an image-to-music exhibition, I worked with a pipeline combining image analysis and music generation. Limited GPU memory forced decisions about model placement and execution order. Moving work to the CPU introduced latency trade-offs, while serial execution helped manage memory pressure.

This experience led me to ask how scheduling and model placement can balance responsiveness, throughput, and memory use.

Reducing inference work while measuring quality

SPTC · KCC 2025 · First-author research

I combined candidate generation, self-evaluation, and selection into a single prompt for small language models. SPTC ran 1.5× faster than ToT with 1.4 percentage points lower accuracy in our evaluation. The study examined both execution cost and failure cases in model self-evaluation.

Parallel execution in document understanding

CoDU · Samsung AI Challenge 2025

I led a three-person team building a layout detection, OCR, and reading-order pipeline. Alongside improving detection accuracy, I parallelized detection and OCR execution. Our team placed 3rd among 210 teams.
